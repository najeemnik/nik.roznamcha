# روزنامچه نیک — Nik Roznamcha

نسخه اولیه MVP برای مدیریت ساده دکان.

## امکانات نسخه 1
- فروش
- خرید
- موجودی
- قرضدار
- مصارف
- گزارش‌ها
- سه زبان: دری، پشتو، انگلیسی
- چاپ بل
- ذخیره اطلاعات در مرورگر
- PWA و قابل نصب روی موبایل

## اجرا
این نسخه برای شروع بدون npm ساخته شده است. کافی است فایل‌ها را روی یک web server یا GitHub Pages/Netlify/Vercel قرار دهید.

برای تست محلی با Python:
`python -m http.server 8000`

سپس:
`http://localhost:8000`

## توجه
این نسخه MVP است و داده‌ها فعلاً در localStorage مرورگر ذخیره می‌شوند. برای استفاده تجاری باید در مرحله بعد حساب کاربری، دیتابیس ابری، احراز هویت، پشتیبان‌گیری و سیستم اشتراک/پرداخت اضافه شود.
